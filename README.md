# Limited Memory Inductive Reasoning Agent

**Team:** Christian Moran, Yasmin Akkaya, Long, Dennis Kulik  
**Course:** CSC 480

---

## Goal

Build an agent that receives a stream of facts, has a fixed memory limit, and must decide what to remember, what to forget, and when to generalize repeated observations into first-order logic rules — so it can answer future queries accurately despite not having seen every fact.

---

## The Core Claim

> A **FOL Compression Agent** answers more queries correctly than naive limited-memory agents because it replaces repeated facts with general, reusable rules.

On chain datasets, the stream contains only adjacent links (e.g. `greater(3, 2)`), while the quiz asks non-adjacent transitive pairs (e.g. `greater(5, 1)`) that were never stored. Baselines answer `"Unknown"`; FOL commits a transitivity rule and derives them.

---

## Agent Types

All agents share the same memory limit for a fair comparison.

| Agent | File | Strategy |
|---|---|---|
| **Simple / Recent** | `agents/simple.py` | Keeps the N most recently seen facts, no rules |
| **Random** | `agents/random.py` | Randomly selects which facts to keep |
| **Importance** | `agents/importance.py` | Keeps facts ranked by a heuristic score, no compression |
| **FOL Compression** *(ours)* | `agents/fol.py` | Learns Horn-clause rules per predicate, evicts derivable facts |

## Graphs and Results

- `benchmark.py` runs all 4 agents on all saved datasets at their target fact limits and writes `results/benchmark.csv`.
- `mem_limit_sweep.py` reruns selected datasets across several fact limits and writes `results/mem_limit_sweep.csv`.
- `graph.py` reads those CSV files and generates timestamped PNG graphs in `results/graphs/`.

`graph.py` supports three graph types:
- `hero` — one dataset, accuracy by agent
- `all-datasets` — grouped bar chart across all datasets or a selected subset
- `tradeoff` — one dataset, accuracy vs memory (fact limit)

## How to Run

### 1. Install dependencies

Requires [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

### 2. Compare all agents

```bash
# default: greater_chain_small
uv run python main.py

# another dataset
uv run python main.py --stream datasets/mixed_chain_small

# show quiz questions answered Unknown
uv run python main.py --stream datasets/greater_chain_large --show-unknowns
```

Set `FACT_LIMIT` in `main.py` to the suggested value for the dataset (see table above).

### 3. FOL-only smoke test

Edit `DATASET`, `FACT_LIMIT`, and `SHOW_UNKNOWNS` in `test_fol.py`, then:

```bash
uv run python test_fol.py
```

### 4. Regenerate datasets (intentional only)

```bash
uv run python generate_dataset.py
```

This overwrites `datasets/`. Only do this if changing benchmark parameters.

### 5. Run the full benchmark matrix

```bash
uv run python benchmark.py
```

This writes `results/benchmark.csv`.

### 6. Run the memory-limit sweep

```bash
uv run python mem_limit_sweep.py
```

This writes `results/mem_limit_sweep.csv`.

### 7. Generate graphs

Hero chart for one dataset:

```bash
uv run python graph.py hero mixed_chain_small
uv run python graph.py hero <dataset_name>
```

Grouped bar chart across all datasets:

```bash
uv run python graph.py all-datasets
```

Grouped bar chart across selected datasets:


```bash
uv run python graph.py all-datasets equals_chain_small equals_chain_large
uv run python graph.py all-datasets <dataset_name_1> <dataset_name_2> ...
```

Memory tradeoff chart for one dataset:

```bash
uv run python graph.py tradeoff greater_chain_large
uv run python graph.py tradeoff <dataset_name>

```

Graph images are written to `results/graphs/` with a timestamp in the filename.

## Design Decisions

### Memory Model
- Bounded fact store and rule store (`fact_limit`, `rule_limit`) with FIFO eviction
- FOL agent: memory and learning trace share one `fact_limit` budget (positives + negatives)
- Negative facts (`not_greater`, etc.) stored in memory and used for rule elimination and quiz answers

### FOL Compression Agent
- On first sight of a predicate, generates candidate Horn rules from `universal.py`
- Accumulates support from fact pairs in a capped learning trace
- Eliminates candidates that derive known false conclusions
- Commits **one rule per predicate** when support plateaus (e.g. transitivity on `greater`, reflexivity on `equals`)
- Evicts memory facts entailed by committed rules
- Answers queries via Z3 with quantified committed rules + remaining facts + negative constraints

### Query Answering (Z3)
For a query `Q`:
1. Assert `NOT Q` — if `unsat`, then `Q` must be true → `"True"`
2. Assert `Q` — if `unsat`, then `Q` contradicts memory → `"False"`
3. Otherwise → `"Unknown"`

For `not_*` queries, the agent checks stored negative facts first, then reasons about the positive form.

### Fixed Datasets
Quiz questions and stream ordering are saved to JSON once. All agents load from the same files so accuracy scores are directly comparable.
